Bemutatkozás

Harmadéves informatika szakos hallgató vagyok a marosvásárhelyi UMFST egyetemen. Szenvedélyem a webes és mobilalkalmazások fejlesztése. Szakmai tapasztalataimat többek között a Topmotive és a Kadeno Solutions cégeknél végzett nyári gyakorlataim során szereztem.

Érdeklődési körök

Szabadidőmben aktívan táncolok egy néptáncegyüttesben. Hatalmas Forma-1 rajongó vagyok, a McLaren és Lando Norris a kedvenceim. Szívesen foglalkozom házi borkészítéssel, valamint szeretek főzni és kísérletezni különleges koktélokkal.
Ezek mellett sokat olvasok, kirándulok es túrázok.

Képességek

  1. Frontend: React, TypeScript, Tailwind CSS
  2. Backend: NestJS, C#, .NET, Java
  3. Mobilfejlesztés: Flutter, Firebase
  4. Hálózatok: Cisco Packet Tracer, Linux Mint
